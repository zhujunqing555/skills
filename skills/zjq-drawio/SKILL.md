# ZJQ_draw.io

把科研图的内容、几何布局和实际显示一起处理。先确定用户这次要改的范围；仅美化时保留标签、公式、连接方向和科学逻辑。使用图纸副本，保持已有用户修改。检查任务只读，不顺便优化。

## 选择工作方式

- 用户要求直接操作桌面 draw.io：优先使用已安装 Scientific Illustrator 的 `drawio_live_*` 工具。先读 [桌面工作流](references/live-workflow.md)。没有暴露这些工具时，使用本技能的本地 stdio MCP 客户端连接**同一个上游服务**，不要把接口握手当成画布已连接。
- 新建离线图：如果 `drawio` 基础技能和 YAML CLI 已安装，可以使用其 YAML 工作流。没有安装时，对小型图可直接构造原生 mxGraph；复杂图先规划结构再选择可用后端，不假装具备未安装的渲染器。
- 修改已有文件：优先保留其原生模型。无须为改几个坐标而强制往返转换全部元素；多页处理、压缩和局部文件补丁交给 `zjq-drawio-tools`。
- 用户只想先看示意图：交付预览，等待用户确认后再制作正式可编辑文件。明确要求直接修改时，不额外引入审批步骤。

## 理解与规划

先读取源图和对象清单；说明本次目标、主阅读方向和必要改动。内容密集时安排等宽列、共享顶/底线、留白和专用连线通道。先调同级对象尺寸，再对齐与等距分布，最后调箭头。不要通过删减研究内容来凑齐高度，除非用户同意内容精简。

科研流程图的具体字体、框型、配色和连线默认见 [科研图样式](references/scientific-style.md)。现有颜色默认保留；用户的当次要求高于默认值。项目书习惯不代表所有期刊的强制规范。

为关键对象使用稳定 id，记录框体、文字、连接的对应关系。复杂修改按区域执行；简单的一个标签或一条箭头修复无需强制整图重做。

## 可编辑性

- 文字放在透明的独立 text 顶点中，框体自身标签留空，除非用户要求组合标签。
- 流程箭头使用一条原生 edge，`source/target` 绑定外框，统一同级线宽和箭头头部；不能拆成横线加三角形。
- 分组方便移动，但组内文字、框体和箭头仍应能分别编辑。
- 图片用于照片、显微图等最小不可拆图源。标题、框线、注释和普通流程结构仍用原生对象；完整流程图截图不能代替可编辑图。
- 公式和名称采用协调的独立文本边界、基线或中心线。保留上下标、斜体与原始科学符号，不把 `z`、`p` 等偷偷改成其他变量。

## 检查与交付

桌面方式：每个完成区域用 `inspect`、`audit_figure` 和新截图检查，再按对象 id 修复；整图完成后核对真实 draw.io 导出 PNG。审计零错误不等于审美自动通过，不能编造主观评分。

检查文字溢出、同级尺寸、意外交叠、箭头方向、连接外框、路径穿字、短箭头只剩箭头头部等实际问题。说明已保留的刻意包含关系，不能把所有背景包含都当成碰撞。

默认交付新 `.drawio` 和真实导出的 PNG，提供绝对路径。可按任务交付 SVG/PDF；清晰度报告用真实像素或实际设置，不把 2000 像素等同于 300 dpi。

**Scientific Illustrator 1.5.4 的 `save_snapshot` 仅保存当前页。** 多页图用 draw.io 完整另存为，或用 `zjq-drawio-tools merge-page` 把当前页快照合回原多页副本并核对页数。不要以单页快照覆盖完整文件。

交付时说明原生文字/形状/箭头/图片数量、结构核验和目视核验结果，以及任何尚未验证的转换限制。PPT 双向同步要单独核对转换器支持的对象，不能从 SVG 外观正确推断 PPT 和 draw.io 已无损同步。

## 本地入口

这些脚本调用已安装的上游 MCP；不在此技能中重复安装或替换插件。

```text
node scripts/live.mjs probe --workdir <工作目录>
node scripts/live.mjs open --input <已保存.drawio> --workdir <工作目录> --hold
node scripts/live.mjs session --workdir <工作目录>
node scripts/live.mjs demo --workdir <测试输出目录> --hold
```

Windows 还可双击 `scripts/启动可控drawio.cmd`，或把图纸拖到它上面：会复制图纸、打开副本并后台保持连接。模型优先使用宿主提供的工具；脚本是工具缺失时的可复用接入方式。

详细配置、实际验证范围和技能来源见 [桌面工作流](references/live-workflow.md)、[来源与能力边界](references/source-audit.md)。
